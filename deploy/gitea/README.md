# Gitea deployment experiment

No deployment files or service exist yet. After contract adoption, select and record
an exact stable version, artifact checksums, configuration and dependency inventory.
Start with stock Gitea, SQLite, local storage and authentication, HTTP/SSH Git, API,
web UI and events. Keep Actions disabled until separately tested.

Do not deploy this spike into an existing forge or create a publicly reachable service
as part of bootstrap. See [disconnected acceptance](../../docs/AIR_GAP_TEST.md).
